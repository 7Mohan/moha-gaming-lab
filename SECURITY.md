# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Moha Gaming Lab and user data seriously. If you discover a security vulnerability, please do not open a public GitHub issue.

Instead, please report vulnerabilities responsibly by:

1. Submitting a private security advisory through GitHub via **Security** > **Report a vulnerability**, or
2. Contacting the project maintainer directly.

### What to Include in Your Report

Please provide:
- A clear description of the vulnerability and its potential impact
- Detailed steps to reproduce the issue (including any proof-of-concept code or requests)
- Any relevant logs, screenshots, or network traces
- Affected routes or components
- Suggestions for mitigation if available

### Response Timeline

- **Acknowledgment**: Within 48 hours of initial receipt
- **Assessment & Triage**: Within 5 business days
- **Resolution & Patch**: Deployed as quickly as feasible depending on severity

Thank you for helping keep Moha Gaming Lab and its users safe.
